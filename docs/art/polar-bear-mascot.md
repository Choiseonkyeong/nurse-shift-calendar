# 북극곰 얼굴 토닥이

사용자 요청에 따라 눈을 뜬 북극곰 얼굴을 이미지 생성 도구로 제작하고, 투명 배경을 유지한 512px WebP로 변환했습니다. `src/assets/polar-bear-face.webp`를 모든 화면에서 사용합니다.

제작 프롬프트: 귀여운 크림색 아기 물개 마스코트처럼 부드럽고 통통한 매력의 독창적인 북극곰 얼굴. 몸 없이 동그란 귀와 얼굴만, 두 눈은 뜨고 작은 반짝이는 짙은 갈색 눈, 작은 코, 미소, 살구색 볼. 따뜻하고 두툼한 윤곽선과 절제된 크림색 셀 셰이딩. 36px에서도 읽히는 단순한 형태. 투명 배경, 글자·모자·소품 없음.
